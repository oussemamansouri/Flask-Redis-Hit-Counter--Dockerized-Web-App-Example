# Flask-Redis Hit Counter: Dockerized Web App Example

A simple web application built with **Flask** that tracks and displays the number of visits using **Redis** as a counter.

This project is fully **Dockerized** and serves as a practical example of using **Docker Compose** to orchestrate a multi-container application consisting of:

- A **Flask** app (web server)
- A **Redis** service (data store for hit counting)

This setup is ideal for learning or demonstrating how to containerize microservices and manage their interaction using Docker Compose.
